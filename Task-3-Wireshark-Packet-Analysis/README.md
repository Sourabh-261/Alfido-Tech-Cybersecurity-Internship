# Task 3: Wireshark Packet Analysis

## Objective

The objective of this task was to capture and analyze network traffic using Wireshark. The analysis focused on identifying common network protocols such as HTTP, DNS, and TCP, understanding packet structure, examining TCP flags, and identifying potentially unusual network traffic.

---

## Tools Used

- Kali Linux
- Wireshark
- Web Browser
- Command Line Network Tools

---

## Test Environment

The packet analysis was performed in a controlled laboratory environment using Kali Linux.

Network traffic was generated by performing normal activities such as:

- Accessing websites
- Performing DNS lookups
- Establishing TCP connections
- Generating HTTP traffic

The captured packets were analyzed using Wireshark filters.

---

## Protocols Analyzed

### 1. TCP

Transmission Control Protocol (TCP) was analyzed to understand how a connection is established between two systems.

The TCP three-way handshake consists of:

1. SYN – The client requests a connection.
2. SYN-ACK – The server acknowledges the request.
3. ACK – The client confirms the connection.

TCP flags such as SYN, ACK, FIN, and RST were examined during packet analysis.
