This repository contains my hands-on work completed during my **Cybersecurity Internship at Alfido Tech**.

### 🌐 Task 2 — Web Application Vulnerability Assessment

**Status:** ✅ Completed

Assessed the deliberately vulnerable **DVWA** web application using Burp Suite and Kali Linux.

**Tools Used:**
- Kali Linux
- DVWA
- Burp Suite
- Firefox

**Activities:**
- Burp Suite proxy configuration
- HTTP request/response interception
- SQL Injection testing
- SQL Injection security-level comparison
- Reflected XSS testing
- Database error analysis
- HTTP header and technology information analysis
- Vulnerability documentation and mitigation recommendations

**Key Findings:**
- SQL Injection — High
- Reflected XSS — Medium
- Database Error Disclosure — Medium
- HTTP Information Disclosure — Low

📁 `Task-2-Web-Application-Security/`
